# Kick Assembler v5.25 Reference

A condensed quick reference to the *Kick Assembler Reference Manual* by Mads Nielsen
(Appendix A, "Quick Reference"), which ships as `KickAssembler.pdf` next to `KickAss.jar`
and at theweb.dk/KickAssembler. The manual is the authority: when a question goes past
these notes, read it rather than guessing.

## Directives (manual Table A.7, complete)

| Directive | Example | Description |
|---|---|---|
| `*` | `*=$1000` | Sets the memory position |
| `.align` | `.align $100` | Aligns the memory position up to a multiple |
| `.assert` | `.assert "Test 1",2+2,4` | Asserts two expressions or code blocks are equal |
| `.asserterror` | `.asserterror "Test 2", List().get(27)` | Asserts an expression/block raises an error |
| `.break` | `.break` | Breakpoint on the next generated bytes |
| `.by` / `.byte` | `.byte $01,$02,$03` | Outputs bytes |
| `.const` | `.const DELAY=7` | Defines a constant |
| `.cpu` | `.cpu _65c02` | Switches instruction set (`_6502` default = legal + illegal, `_6502NoIllegals`, `dtv`, `_65c02`) |
| `.define` | `.define width, height {...}` | Runs a block in function mode to define values |
| `.disk` | `.disk [...] {...}` | Creates a D64 image |
| `.dw` / `.dword` | `.dword $12341234` | Outputs 4-byte values |
| `.encoding` | `.encoding "screencode_upper"` | Sets text encoding (`ascii`, `petscii_mixed`, `petscii_upper`, `screencode_mixed`, `screencode_upper`) |
| `.enum` | `.enum {on, off}` | Defines a series of constants |
| `.error` / `.errorif` | `.errorif x>10 "not good!"` | User-raised error |
| `.eval` | `.eval x=x+y/2` | Evaluates a script expression |
| `.file` | `.file [name="myfile.prg" segments="Code, Data"]` | Writes a prg/bin from segments |
| `.filemodify` | `.filemodify Encrypt(33)` | Modifies this file's output |
| `.filenamespace` | `.filenamespace myspace` | Namespaces the rest of the file |
| `.fill` | `.fill 10, i*2` | Fills bytes from an expression (`i` = index) |
| `.fillword` | `.fillword 10, i*$102` | Fills words |
| `.for` | `.for(var i;i<10;i++) {...}` | For loop |
| `.function` | `.function area(h,w) {..}` | Defines a script function |
| `.if` | `.if(x>10) {...}` | Conditional assembly |
| `.import binary` | `.import binary "Music.bin"` | Imports a binary file |
| `.import c64` | `.import c64 "Music.c64"` | As binary, skipping the 2 load-address bytes |
| `.import text` | `.import text "scroll.txt"` | Imports a text file |
| `.label` | `.label color=$d020` | Assigns an expression to a label |
| `.lohifill` | `.lohifill $100, i*40` | Fills paired lo/hi byte tables |
| `.macro` | `.macro BasicUpstart() {...}` | Defines a macro |
| `.memblock` | `.memblock "New block"` | Starts a new named memory block |
| `.modify` | `.modify Encrypt(27) {...}` | Modifies a code block's output |
| `.namespace` | `.namespace myspace {..}` | Local namespace |
| `.pc` | `.pc=$1000` | Same as `*=` |
| `.plugin` | `.plugin "plugins.macros.MyMacro"` | Registers a Java plugin |
| `.print` / `.printnow` | `.print "Hello"` | Console output (last pass / immediately) |
| `.pseudocommand` | `.pseudocommand mov src:tar {...}` | Defines a pseudo command |
| `.pseudopc` | `.pseudopc $2000 {...}` | Assembles for a different run address than the store address |
| `.return` | `.return 27` | Returns a value from a function |
| `.segment` | `.segment Data "My Data"` | Switches segment |
| `.segmentdef` | `.segmentdef Data [start=$1000]` | Defines a segment |
| `.segmentout` | `.segmentout [segments="DRIVE_CODE"]` | Emits an intermediate segment's bytes here |
| `.struct` | `.struct Point {x,y}` | User-defined structure |
| `.te` / `.text` | `.text "hello"` | Outputs text bytes in the current encoding |
| `.var` | `.var x=27` | Defines a variable |
| `.while` | `.while(i<10) {...}` | While loop |
| `.wo` / `.word` | `.word $1000,$1012` | Outputs 2-byte values |
| `.zp` | `.zp { label: .byte 0 ... }` | Marks unresolved labels as zero page |

Preprocessor (separate from the above, `#` prefix): `#define`, `#undef`, `#if`, `#else`,
`#elif`, `#endif`, `#import`, `#importif`, `#importonce`. **`#import` is the current form;
`.import source` and `.importonce` are deprecated.**

## Syntax notes

- Comments are `//` and `/* */`.
- Numbers: `$ff` hex, `%1010` binary, `27` decimal, `27.4` float (the script language is
  floating point; values are truncated when emitted).
- Labels end in `:`. Multi-labels `!` / `!loop:` are re-usable; refer to them with `!-`
  (previous) and `!+` (next) — useful for short local loops.
- `<expr>` and `>expr` take low and high byte.
- Label scopes: `{ }` around a block makes its labels local. Macros and pseudocommands get
  their own scope automatically.
- Built-in C64 color constants (manual Table 14.2): `BLACK` 0, `WHITE` 1, `RED` 2, `CYAN` 3,
  `PURPLE` 4, `GREEN` 5, `BLUE` 6, `YELLOW` 7, `ORANGE` 8, `BROWN` 9, `LIGHT_RED` 10,
  `DARK_GRAY`/`DARK_GREY` 11, `GRAY`/`GREY` 12, `LIGHT_GREEN` 13, `LIGHT_BLUE` 14,
  `LIGHT_GRAY`/`LIGHT_GREY` 15.
- `BasicUpstart2(label)` emits a BASIC stub at `$0801` that `SYS`es to `label`; the code
  then normally starts at `$0810`. `BasicUpstart(address)` is the raw variant.
- Value types available to the script language: Number, String, Char, Boolean, List,
  Hashtable, Struct, Matrix, Picture (`LoadPicture`), SidFile (`LoadSid`),
  BinaryFile (`LoadBinary`), OutputFile (`createFile`), Null, 65xxArgument.

## Command line

```bash
java -jar KickAss.jar source.asm -odir bin
```
Useful options: `-o <file>` output name, `-odir <dir>` output directory,
`-symbolfile` write a VICE `.sym`, `-debugdump`/`-debug` write `.dbg`, `-showmem` print the
memory map, `-bytedump` write `ByteDump.txt`, `-define SYMBOL`, `-libdir <dir>`,
`-vicesymbols`, `-afo`/`-asminfo` assembler info for IDEs.

`KickAss.cfg` beside `KickAss.jar` is read automatically on every build; command-line
options are applied after it. Its options take their value after a **space** (`-libdir .`):
`-libdir=.` is parsed as an input filename and the build fails with
`Inputfile '-libdir=.' doesn't exist` or `Already have an inputfile`. There is no
`-output-dir`; it is `-odir`. Keep debug outputs (`-showmem`, `-symbolfile`, `-vicesymbols`,
`-debug`, `-bytedump`) for the single build that needs them rather than the cfg.

## Gotchas

- The assembler runs multiple passes with a flexible pass algorithm. A forward-referenced
  label used in a zero-page-capable instruction assembles as **absolute** unless you mark it
  `.zp` or define it earlier — silently costing a byte and a cycle per access.
- `.fill n, expr` evaluates `expr` once per byte with `i` bound to the index; it is the
  idiomatic way to generate sine tables and graphics at assembly time.
- Illegal opcodes are enabled by default. If you want the assembler to reject them, use
  `.cpu _6502NoIllegals`.
- Segments write nothing unless a `.file` or the default segment picks them up — "where did
  the output go?" is a whole section of the manual for a reason.
